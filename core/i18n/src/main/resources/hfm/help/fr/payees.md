# Bénéficiaires

Les bénéficiaires sont les personnes et les entreprises que vous payez ou qui vous paient : l’épicerie, Hydro-Québec, votre employeur. Une liste propre rend les opérations plus faciles à lire et à rechercher. Vous les trouvez dans Réglages, sous Bénéficiaires.

## Ajouter un bénéficiaire

- Cliquez sur Ajouter.
- Inscrivez le Nom du bénéficiaire.
- Au besoin, choisissez une Catégorie par défaut. Quand vous saisissez une opération pour ce bénéficiaire, ou que vous en importez une d’un relevé, cette catégorie est proposée.
- Cliquez sur Enregistrer.

## Reconnaître un bénéficiaire sur les relevés

Les banques impriment souvent les noms sous une forme abrégée ou bizarre, comme AMZN MKTP. Un alias relie ce texte au bon bénéficiaire.

- Sélectionnez le bénéficiaire dans la liste.
- Inscrivez le texte dans Alias, par exemple AMZN MKTP.
- Cliquez sur Ajouter l’alias.

Quand une ligne importée contient un alias, sans égard aux majuscules, elle reçoit le nom propre du bénéficiaire.

## Modifier ou masquer un bénéficiaire

- Sélectionnez un bénéficiaire pour changer son nom ou sa catégorie par défaut, puis cliquez sur Enregistrer.
- Cochez Archivé (masqué des listes) pour un bénéficiaire que vous n’utilisez plus. Les opérations passées le gardent.

Pour aller plus loin, par exemple choisir une catégorie selon le montant, utilisez les Règles de catégorie.
