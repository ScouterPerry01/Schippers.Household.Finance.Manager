# Règles de catégorie

Les règles de catégorie attribuent automatiquement une catégorie aux opérations importées. Quand la description d’une opération importée contient le texte d’une règle, elle reçoit la catégorie de cette règle. Vous les trouvez dans Réglages, sous Règles de catégorie.

## Comment les règles s’appliquent

À l’importation d’un relevé, chaque nouvelle ligne est comparée aux règles, de haut en bas. La première règle qui correspond donne la catégorie. Si aucune ne correspond, l’application prend la catégorie par défaut du bénéficiaire, puis celle que vous avez déjà utilisée pour ce bénéficiaire dans ce compte. Vous pouvez toujours changer la catégorie ensuite.

## Ajouter une règle

- Cliquez sur Ajouter.
- Dans La description contient, inscrivez le texte à chercher, par exemple HYDRO-QUEBEC ou PAIE.
- Choisissez la Catégorie.
- Au besoin, remplissez Montant d’au moins et Montant d’au plus pour limiter la règle à une fourchette. C’est utile quand un même magasin vend de tout, ou qu’un dépôt de l’employeur peut être une paie ou un remboursement de dépenses.
- Cliquez sur Enregistrer.

## Consulter ou supprimer une règle

Dans la liste, chaque règle se lit ainsi : le texte, une flèche, puis la catégorie. Sélectionnez une règle pour voir ses limites de montant. Pour la retirer, cliquez sur Supprimer. Supprimer une règle ne change pas les opérations déjà importées.

Les alias, dans l’écran Bénéficiaires, nettoient les noms; les règles choisissent les catégories. Les deux vont bien ensemble.
