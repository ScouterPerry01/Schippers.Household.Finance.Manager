# Budgets

L’écran Budgets compare ce que vous prévoyez dépenser dans chaque catégorie avec ce que vous dépensez vraiment. Il fait partie du groupe Argent dans le menu.

Chaque ligne montre une catégorie avec le montant dépensé (ou reçu, pour un revenu), le montant budgété, puis ce qui reste ou le dépassement. Les flèches du haut font passer d’un mois à l’autre. Cochez Année complète pour voir toute l’année plutôt qu’un seul mois.

## Laisser l’application suggérer

Si vous avez déjà un historique, choisissez Suggérer d’après les 12 derniers mois. L’application affiche la moyenne mensuelle de chaque catégorie sur les 12 derniers mois complets. Cochez les catégories à budgéter, puis choisissez Créer les budgets. Les catégories qui ont déjà un budget sont signalées. Seuls les comptes partagés comptent, puisque chaque utilisateur du ménage voit les budgets.

## Ajouter un budget vous-même

Choisissez Ajouter un budget. Choisissez la catégorie et entrez le montant. Sous Le budget est, choisissez Mensuel ou Annuel. Un budget annuel convient aux frais qui reviennent une ou deux fois par année, comme l’assurance ou l’impôt foncier. Indiquez le premier mois visé. Le budget d’une catégorie couvre aussi ses sous-catégories, sauf celles qui ont leur propre budget.

## Reporter les montants

Cochez Reporter au mois suivant ce qui n’est pas dépensé ou ce qui est dépassé si vous voulez que le reste, ou le dépassement, passe au mois suivant. La ligne indique alors le montant reporté.

## Modifier un budget

Cliquez sur une ligne pour en changer le montant ou les réglages, ou pour la supprimer.

Le tableau de bord montre les dépenses du mois par rapport à vos budgets et le nombre de catégories qui dépassent le budget. Un rapport de budget est aussi offert dans les Rapports.
