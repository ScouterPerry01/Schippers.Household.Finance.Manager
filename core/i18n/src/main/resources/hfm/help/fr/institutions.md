# Institutions financières

Les institutions financières sont les banques, caisses, courtiers et autres entreprises qui tiennent vos comptes. En les inscrivant une fois, vous pouvez relier chaque compte à son institution et garder ses coordonnées sous la main. Vous les trouvez dans Réglages, sous Institutions financières.

## Ajouter une institution

- Cliquez sur Ajouter.
- Inscrivez le Nom, par exemple Desjardins ou Banque Nationale.
- Au besoin, ajoutez la Succursale, le Numéro d’institution (3 chiffres) et le Numéro de transit (5 chiffres). Ce sont les numéros imprimés sur vos chèques et sur un formulaire de dépôt direct.
- Au besoin, ajoutez le Site Web, le Téléphone et des Notes.
- Cliquez sur Enregistrer.

## Modifier une institution

Sélectionnez-la dans la liste, changez ce qu’il faut, puis cliquez sur Enregistrer. Le changement s’applique partout où l’institution est utilisée.

## À quoi ça sert

- Quand vous ajoutez un compte dans Comptes, vous pouvez choisir son institution.
- Le téléphone et le site Web sont pratiques quand une carte est perdue ou qu’un paiement doit être arrêté.
- Le sommaire Urgence et succession énumère les institutions du ménage, ce qui aide la personne qui devrait prendre la relève.

Les numéros de compte sont gardés avec chaque compte, pas ici.
