# Rates and rules

This screen lists every rate, limit, threshold and lead time the app applies: TFSA limits, sales taxes, income tax brackets, reminder lead times and more. Each value has the date it takes effect and, when it differs, its province or territory. The official values are built in. It is in Settings, under Rates and rules.

## Find a rule

The rules are grouped by area on the left. Type part of a name or key in Filter by name or key; accents do not matter. Click a rule to see it on the right: what it is, its type, the value in effect today (for each province and territory when it can differ, yours first) and the history of all its values.

## Add a value

When a new limit or rate is announced before the app is updated, an administrator can add it under Add a value:

- Effective from: the date the value takes effect. It applies to everything dated on or after it.
- Province or territory: for a rule that differs by province, one province or All provinces and territories. A province's own value always wins over the value for all.
- The value: a rate as a percentage, such as 9.975 for 9.975 %; an amount in dollars; days; yes or no; a month and day; or, for brackets, one row per threshold with its rate.
- Note: where the figure comes from.

The line under the form shows the value before and after the date. Built-in values stay in the history. A household value can be deleted with Delete; the value before it then applies again. Other users see the values but cannot change them.
