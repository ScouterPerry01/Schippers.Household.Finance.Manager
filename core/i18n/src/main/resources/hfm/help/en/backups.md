# Backups

Backups keeps copies of the whole household so you can recover from a broken disk, a lost computer or a mistake. You find it in the Settings group of the menu.

A backup is still encrypted. Restoring one needs your password or recovery key. Each backup is checked right after it is made.

## Choose where backups go

Click Choose folder… and pick a folder. For real protection, choose an external drive, a network drive or a cloud folder such as OneDrive, Google Drive or Dropbox, not the same disk as the household.

## Set the schedule

- Automatic backups: Off, Every day or Every week. The schedule runs while the household is open.
- Versions to keep: how many backups stay in the folder. Older ones are deleted only after a new backup passes its check.

Click Save after changing these.

## Back up now

Click Back up now at any time. The screen shows when the last backup was made and any problem with it. The list below shows the backups in the folder; click Check beside one to confirm it is complete and readable.

If no backup has worked for 7 days, the dashboard reminds you.

## Restore or move to a new computer

To restore a backup, or to move the household to a new computer, lock the household and choose Restore from a backup… on the start screen. A backup is always restored into a new folder, never over an existing household.

## Export all data

Export all data… saves everything you can see in open formats (CSV and JSON). The export is not encrypted: anyone with the file can read it. Keep it somewhere safe and delete it when you are done.
