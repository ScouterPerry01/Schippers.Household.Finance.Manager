# Keyboard shortcuts and accessibility

RANN's Roost can be used from the keyboard, read by a screen reader, and shown larger or in dark colours. This chapter lists every shortcut the app adds to the usual ones, then what helps people who see, read or move differently.

## Shortcuts anywhere {#anywhere}

@index: shortcuts; keyboard; hot keys

These work on every screen:

- **F1**: opens the Help panel on the topic for the screen shown. Press F1 again, or Escape, to close it. It works on the start screens too, before a household is open.
- **Shift+F1**: opens the manual on the chapter about the screen shown. See [Using the Manual window](welcome#manual-window).
- **Ctrl+F**: puts the cursor in the search box at the top of the window, ready to type. It works while a household is open.

## Moving around with the keyboard {#keyboard-navigation}

@index: Tab; Shift+Tab; focus; keyboard navigation

These are the usual keys of Windows and Linux, and they work in the app too:

- **Tab**: moves to the next field, button or checkbox.
- **Shift+Tab**: moves back to the previous one.
- **Enter** or **Space**: presses the button that has the focus.
- **Escape**: closes a window opened over the screen.

## In the search box {#search-box}

@index: search shortcut

- **Enter**: searches for what you typed. Type at least two characters; a shorter search is ignored.

The results open in a window; **Close** closes it. See [Searching](basics#search).

## In an account's register {#register}

@index: register shortcuts; enter a transaction

The form below the transactions, where you enter or change a transaction, answers to two keys wherever the cursor is in it:

- **Enter**: saves the transaction, the same as its save button.
- **Escape**: clears the form without saving, to start over.

After a save, the form is cleared for the next transaction and keeps the date, so you can enter a whole stack of receipts from the same day without the mouse: Tab from field to field, then Enter. See [Accounts](accounts).

## In date fields {#date-fields}

@index: date shortcut; plus key; minus key; next day

- The plus key, typed at the end of a valid date, moves it one day later (2026-03-05 + becomes 2026-03-06).
- The minus key, typed at the end of a valid date, moves it one day earlier.

Type the key several times to move several days. Dates are typed as YYYY-MM-DD; see [Date fields](basics#date-fields).

## In amount fields {#amount-fields}

@index: calculator; arithmetic; amount shortcut

Amount fields are calculators. Type a sum and the result shows under the field:

- Add and subtract with + and -, as in 12.50 + 3.25.
- Multiply with * or ×, as in 3 * 4.99.
- Divide with / or ÷, as in 120 / 4.
- Group with parentheses, as in (100 - 20) / 4.

Only the final result is rounded to the cent. See [Amount fields and the calculator](basics#amount-fields).

## In drop-down lists {#pickers}

@index: filter a list; type to search

Typing in a drop-down list keeps only the choices that contain what you typed. This is the quickest way to pick a category, an account or a payee in a long list.

## In forms that open in a window {#dialogs}

@index: Escape key; close a window

- **Escape**: closes the window without saving, the same as **Cancel**.
- Tab to **Save** and press Enter or Space to save.

## In the Help panel {#help-panel}

- The cursor starts in **Search the guide**: type to search at once.
- **Escape** or **F1**: closes the panel.

## Accessibility {#accessibility}

@index: accessibility; low vision; screen reader; dark mode; large text

### Text size and colours {#text-size-colours}

Under [Display and accessibility](display), in the Settings group:

- **Text size**: from 90 % to 150 %. Every screen, and the manual, grows with it, and the menu on the left widens so its names stay on one line. A sample line shows the size chosen.
- **Colours**: as the system is (light or dark), always light or always dark. The charts follow the same choice.

Each computer keeps its own choice, so a large screen and a laptop can differ.

### Screen readers {#screen-readers}

@index: Narrator; NVDA; Orca

Screen readers, such as Narrator or NVDA on Windows and Orca on Linux, read the labels of fields, buttons and checkboxes. The app also tells them:

- whether each group of the menu on the left is open or closed;
- that each group of the menu at the top opens a menu;
- whether each step of the Getting started guide on the Dashboard is done or to do.

### Fewer things to remember {#memory-aids}

- The reminder banner and the computer notifications say what is due, in words, so nothing has to be remembered.
- The Dashboard's Getting started guide shows what to do next, and its Needs your attention list shows what waits for a decision.
- Every field keeps its label in view while you type in it.

## Quick reference {#quick-reference}

@index: shortcut list; cheat sheet

- F1: help on this screen.
- Shift+F1: manual on this screen.
- Ctrl+F: search box.
- Enter in the search box: search.
- Enter in a register's entry form: save the transaction.
- Escape in a register's entry form: clear the form.
- Escape in a window: close without saving.
- + or - after a date: one day later or earlier.
- Tab and Shift+Tab: next and previous field or button.
- Enter or Space: press the button that has the focus.
