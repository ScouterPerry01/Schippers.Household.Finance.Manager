# Premiers pas avec les documents

Ce chapitre montre comment faire entrer vos reçus et factures dans RANN's Roost, vérifier ce qui a été lu et classer chacun avec son paiement. Chaque étape renvoie à la description complète dans [Documents](documents).

## Avant de commencer {#before-you-begin}

- Les documents sont conservés chiffrés dans le dossier du ménage et lus sur cet ordinateur. Rien n’est envoyé ailleurs, sauf si vous choisissez de faire lire un document par l’IA.
- Le classement fonctionne mieux quand vos comptes et vos opérations récentes sont dans l’application, pour qu’un reçu puisse être jumelé à son paiement. Voir [Premiers pas avec votre argent](start-money).
- Les fichiers PDF, JPEG, PNG et HEIC sont acceptés, ainsi que les courriels enregistrés à partir de votre logiciel de courriel.

## Faire entrer vos premiers documents {#bring-in}

1. Ouvrez **Documents** dans le groupe Argent du menu.
2. Faites glisser quelques reçus ou factures (PDF ou photos) de votre ordinateur sur l’écran, ou cliquez sur **Importer des fichiers…** et choisissez-les.
3. Attendez pendant que le bouton affiche **Lecture…**. La première lecture d’une session prend un peu plus de temps.
4. Un message indique combien de documents ont été ajoutés. Ils attendent dans l’onglet **À vérifier**.

Voir [Faire entrer des documents](documents#adding-documents).

## Vérifier ce qui a été lu {#check}

1. Dans **À vérifier**, cliquez sur **Vérifier** sur un document. Le document est à gauche, ce qui a été lu à droite.
2. Comparez **Commerce ou fournisseur**, **Type**, **Date** et **Total** avec l’image. Les champs marqués « À vérifier : difficile à lire » méritent un examen attentif.
3. Corrigez ce qui est faux. L’application retient vos corrections pour les prochains documents du même commerce.

Voir [La fenêtre du document](documents#document-window).

## Classer chaque document {#file}

Sous **Classer avec**, choisissez :

1. Si le paiement est déjà dans vos livres (importé de la banque, par exemple), cliquez sur **Joindre** à côté de l’opération correspondante.
2. S’il s’agit de l’une de vos factures, cliquez sur **Inscrire le montant sur cette facture** : le montant est inscrit sur l’échéance la plus proche de la facture.
3. Si le paiement n’est pas encore dans les livres (un achat payé comptant, par exemple), cliquez sur **Nouvelle opération à partir de ce document**, choisissez le compte sous **Payé avec** et une **Catégorie**, et cliquez sur **Enregistrer**.
4. Sinon, cliquez sur **Classer sans joindre**. Vous le retrouverez plus tard dans **Tous les documents**.

Cochez **Conserver ce document** sur les garanties et les reçus des biens que vous possédez, pour qu’ils n’apparaissent jamais parmi les anciens documents à supprimer.

Voir [Classer un document](documents#filing).

## Lire les documents difficiles avec l’IA {#ai}

Les reçus froissés, les longs relevés et les talons de paie sont souvent mieux lus par l’IA. La lecture par IA est facultative ; elle utilise votre propre clé Anthropic, à laquelle un petit montant est facturé par document, estimé avant tout envoi.

1. Activez-la et ajoutez votre clé dans [Lecture par IA](ai), dans le groupe Réglages du menu.
2. Dans la fenêtre d’un document, cliquez sur **Lire avec l’IA**.
3. Dans la fenêtre qui s’ouvre, faites glisser sur ce que vous voulez masquer, comme un numéro de compte complet, puis cliquez sur **Envoyer**.

Un relevé lu par l’IA peut ensuite être rapproché avec son compte, et un talon de paie inscrit comme votre paie. Voir [Lire un document avec l’IA](documents#read-with-ai).

## À partir de votre téléphone {#phone}

Avec RANN's Roost Mobile, photographiez vos reçus au moment où vous les recevez.

1. Jumelez le téléphone dans l’écran Téléphones, dans le groupe Réglages du menu. Voir [Premiers pas avec le téléphone](start-phone).
2. Prenez des photos sur le téléphone, ou saisissez une dépense rapide. Vous pouvez ajouter une note vocale.
3. Tant que le ménage est ouvert sur cet ordinateur, les captures arrivent dans l’onglet **À vérifier**. Vérifiez-les et classez-les comme plus haut.

## Numériseur et factures électroniques {#scanner}

1. Cliquez sur **Dossier surveillé…** puis sur **Choisir le dossier…**, et choisissez le dossier où votre numériseur enregistre ses fichiers, ou celui où vous enregistrez vos factures électroniques téléchargées. Cliquez sur **Enregistrer**.
2. Dès lors, chaque fichier enregistré dans ce dossier est importé en moins d’une minute et déplacé dans un dossier « Imported » à l’intérieur.
3. Pour un reçu reçu par courriel, enregistrez le courriel comme fichier (.eml) à partir de votre logiciel de courriel dans le même dossier, ou déposez-le sur l’écran.

Voir [Le dossier surveillé](documents#watched-folder).
