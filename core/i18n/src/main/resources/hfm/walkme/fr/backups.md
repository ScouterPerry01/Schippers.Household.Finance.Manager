# Sauvegardes
@about: Choisissez un endroit sûr pour les sauvegardes et leur fréquence, puis faites la première.

## Ouvrir Sauvegardes {#open}
@screen: BACKUPS
@done: screen
@manual: backups#about-backups

Une sauvegarde est une copie chiffrée de tout le ménage, vérifiée une fois faite. Dans le menu, ouvrez **Réglages**, puis **Sauvegardes**.

## Choisir le dossier {#folder}
@screen: BACKUPS
@target: backups.folder
@manual: backups#settings

Cliquez sur **Choisir le dossier…** et choisissez un disque externe, un lecteur réseau ou un dossier infonuagique (OneDrive, Google Drive, Dropbox), pas le disque où se trouve le ménage. Les sauvegardes y restent chiffrées.

Seul un administrateur peut changer les réglages de sauvegarde.

## À quelle fréquence {#schedule}
@screen: BACKUPS
@target: backups.frequency
@manual: backups#settings

Choisissez **Sauvegardes automatiques** : **Chaque jour** ou **Chaque semaine**. Les sauvegardes se font pendant que le ménage est ouvert ; celle qui était due pendant que l’ordinateur était éteint se fait peu après que vous l’ouvrez.

**Versions à conserver** indique combien en garder dans le dossier ; cliquez sur **Enregistrer** après l’avoir changé.

## Sauvegarder maintenant {#now}
@screen: BACKUPS
@target: backups.now
@done: added backup
@manual: backups#back-up-now

Cliquez sur **Sauvegarder maintenant**. La sauvegarde est faite, vérifiée, et les plus anciennes au-delà du nombre à conserver sont supprimées. La date de la dernière bonne sauvegarde s’affiche à côté du bouton.

## Restaurer plus tard {#restore}
@manual: backups#restore

Pour restaurer, ou pour passer à un nouvel ordinateur : cliquez sur **Verrouiller** et **Retour**, puis à l’écran d’accueil cliquez sur **Restaurer une sauvegarde…**, choisissez le fichier de sauvegarde et le dossier où mettre le ménage. Un ménage existant n’est jamais écrasé.
